# Contribution ideas

These are issue ideas, not release commitments. Please check the repository's current issues before opening a duplicate.

- **Recorder guidance:** document browser permission prompts, start/stop controls, and how to find a saved recording. Do not request broader screen access than needed.
- **Fixture procedure:** improve the fictional bundled fixture example with observable checks and a reviewer-friendly reproduction path.
- **Failure messages:** make fixture failures state which observable check failed and what evidence is available, without presenting guesses as diagnosis.
- **Keyboard accessibility:** report the page and control where keyboard focus becomes unclear, trapped, or unavailable, with a text reproduction.
- **Client compatibility:** document one MCP client's installation and demonstrate data retrieval; distinguish a handshake from actual recording-image delivery and interpretation.

Use fictional data or public resources. Do not attach personal recordings, private screenshots, credentials, cookies, or customer data. See [CONTRIBUTING.md](../CONTRIBUTING.md).
