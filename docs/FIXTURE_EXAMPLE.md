# Example: save a fictional fixture draft

This example uses the bundled local practice app to retain a generated file named `demo-orbit.mp4` with the fictional caption `A paper moon over a fictional harbour.` The fixture creates harmless generated bytes; it does not preserve real video or publish a post.

The executable procedure is [examples/fixture-draft.json](examples/fixture-draft.json). Its four actions select media, fill the caption, save the draft, then compare the receipt ID, filename, and caption with the fixture's retained draft list. The `check` text documents expected evidence; it is not arbitrary executable code.

To reproduce from a source checkout, install the project and test dependencies as shown in [CONTRIBUTING.md](../CONTRIBUTING.md), install matching Playwright Chromium, then run:

```sh
python -m pytest -q tests/test_backend.py -k documented_fixture_example
```

The test drives real Chromium against an isolated local app. It covers a normal save, a changed-label stop, a reviewed correction, and preservation of the earlier procedure snapshot. All fixture values are fictional. Generated test data and screenshots are temporary and should not be committed.

This example verifies the bundled fixture path only. It does not verify screen-capture permissions, arbitrary websites, automatic recording analysis, original-media reuse, or live publishing.
