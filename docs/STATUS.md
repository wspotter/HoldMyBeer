# Capabilities and limits

LikeThis is an experimental local application. Install it from the public source repository as described in the [README](../README.md).

## Available

- Record a browser task or import a video, then save it under an app, task, and version.
- Browse saved tasks and earlier versions; edit into a new version; archive and restore tasks.
- Connect a compatible MCP client to inspect bounded session data and timestamped recording frames, and submit a separate review proposal.
- Review proposals manually in LikeThis. Review approval records understanding; it does not itself authorize execution.
- Preview and explicitly approve deterministic file recipes for batch rename, organize by extension, and CSV summary; recipes have sample checks and show before/after changes.
- Run the fixed four-action procedure against the bundled local fixture after review and explicit trial authorization.
- Prepare a bounded public GitHub issue brief, review its exact plan, approve it, and run the named read-only browser procedure.

## Not available

- Automatic assistant dispatch or proof that a configured client loaded the server.
- General-purpose execution or replay of recorded personal workflows.
- Arbitrary website or shell actions through the fixture procedure; generic GUI and terminal steps require agent assistance.
- Login to GitHub, issue creation or modification, social publishing, or a claim that an issue report is exhaustive.
- A managed production service or an independently validated pilot.

See [the contract](CONTRACT.md) for precise execution boundaries and [verification guidance](VERIFICATION.md) for reproducible local checks. Client configuration examples are not client acceptance evidence.
