# Open areas

LikeThis is an experimental project. Useful future work includes:

- Improve keyboard accessibility and first-run recording guidance.
- Gather independent usability feedback using fictional or public fixture data.
- Expand reproducible installation checks across supported operating systems and MCP clients.
- Design richer action and success-check contracts before considering any execution beyond the bundled fixture and named GitHub issue brief.
- Improve local data lifecycle, backup, and upgrade documentation.

These are areas for contribution, not promises of a release schedule. General replay of personal recordings and automatic assistant review dispatch are not current capabilities. See [current status](STATUS.md) before proposing work that depends on them.
